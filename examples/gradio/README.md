# Jev 上下文压缩案例

一个中文实验台，用来观察：**Agent 的对话变短以后，后续回答需要的信息是否还在？**

例如，Agent 修复 Bug 时会读取文件、运行测试，产生大量工具记录。Jev 对这些记录评分，删除不再需要的调用或截短输出，保留下来的内容维持原文。实验台再让同一个大模型分别阅读原始和压缩后的对话，回答相同问题，观察压缩的影响。

## 谁负责什么

| 组件 | 作用 |
| --- | --- |
| Jev | 给工具调用和输出打保留分数，现有 TypeScript 库按阈值执行压缩 |
| 回答模型（例如 DeepSeek） | 分别读取两份上下文，回答同一组问题 |
| 实验台 | 展示删减过程、检查原文证据、核对回答中的标准答案要点 |

实现方式是 **Gradio 页面 → 本地 Node 适配层 → 原有压缩库**，没有重新实现核心压缩算法。

## 本地启动

需要 **Node.js 22+、Python 3.11+**。以下命令在项目根目录的 PowerShell 中执行：

```powershell
npm ci
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r examples/gradio/requirements.txt
```

在项目根目录创建 `.env`：

```dotenv
# 必需：Jev 压缩评分
TYPESAFE_API_KEY=你的TypeSafe密钥

# 可选：启用真实回答对比（这里以 DeepSeek 为例）
ANSWER_BASE_URL=https://api.deepseek.com
ANSWER_API_KEY=你的DeepSeek密钥
ANSWER_MODEL=deepseek-flash
```

启动：

```powershell
npm run demo:gradio
```

打开 [本地实验台](http://127.0.0.1:7860/)，终端按 `Ctrl+C` 停止。已有依赖和配置时，直接运行启动命令即可。

## 怎么体验

### 1. 上下文压缩实验

1. 选择内置样例，先阅读对话预览；也可导入符合项目格式的 JSON。
2. 点击 **开始压缩**，调用真实 Jev API 获取保留分数。
3. 查看字符减少比例，以及逐条对齐的原始／压缩后记录。展开工具记录可以查看评分和输出。
4. 调整 **保留阈值**，观察哪些记录被保留、截断或删除。

阈值越高，通常删得越多。**调整阈值只复用已有评分，不会再次调用 Jev。** 更换对话、任务目标或保护最近消息数后，需要重新点击开始压缩。首条消息及保护范围内的工具记录会受到保护。

### 2. 关键信息验证

1. 点击 **下一步：验证关键信息**，确认当前样例、阈值、回答模型和验证问题。
2. 关键原文会自动在本地检查；没有回答模型时，也可仅使用这项检查。
3. 点击 **开始回答对比**，让同一个模型分别阅读原始和压缩后的完整对话。
4. 查看匹配数和逐题回答，使用 **只看需关注** 查找未匹配或证据缺失的题目。

标准答案不会发送给回答模型。实验台按预先设置的答案要点核对回答，不是让模型自行给自己打分。

## 建议先试的案例

- **Bug 修复**：看禁止修改的目录、未解决错误、通过的测试和后续任务是否留下。
- **资料检索**：看关键数字、来源和限制条件是否保留。
- **多轮需求修改**：看最终要求是否仍能与旧要求区分。
- **困难样例**：恢复批次、队列和错误代码只存在于旧工具输出中。先用默认阈值，再调高阈值并重新运行回答对比，观察是否出现信息丢失。

困难样例尤其值得观察：**原库发送给 Jev 的评分状态省略了工具输出正文，只保留状态和长度等信息。** Jev 无法直接看到其中的唯一线索，具体保留情况要以本次结果为准。

## 怎样理解结果

| 观察到的结果 | 可以得出的结论 |
| --- | --- |
| 关键原文仍在 | 指定的证据片段被保留，不代表模型一定能答对 |
| 原始回答匹配，压缩后未匹配 | 疑似受到压缩影响，需检查丢失内容和真实回答 |
| 两边都未匹配 | 暂不能直接归因于压缩 |
| 两边都匹配 | 已测问题未发现回答退化，不代表所有信息都无损 |

答案要点匹配可能误判否定表达、矛盾或同义改写，需要人工复核。内置数据只有 **4 个手工样例、17 道题**，用于理解机制，不代表通用任务成功率。

## 使用注意

- “开始压缩”会向 TypeSafe 发送对话正文和工具输入；“开始回答对比”会向配置的回答服务发送两份完整上下文，可能消耗 API 额度。导入前请移除敏感信息。
- 密钥仅在本地服务端读取；`.env` 已被 Git 忽略，不要把密钥写进对话或提交到仓库。
- 默认仅本机访问，不公开分享。修改输入或参数会清除旧验证结论；刷新页面后需重新压缩。
- 字符减少比例不是 token 或费用节省，Jev 的保留分数也不是回答正确率。

更多实现细节和导入格式见[项目 README](../../README.md)。
